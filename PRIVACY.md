# Privacy Policy — Google Chat Markdown Table

_Last updated: 2026-11-13_

Google Chat Markdown Table ("the extension") renders markdown tables that appear in Google Chat messages as HTML tables.

## Data collection

The extension **does not collect, store, transmit, or share any data**.

- Message text is read only inside your browser, only to detect markdown tables and draw them on the page.
- Nothing is sent to any server. The extension makes no network requests.
- Nothing is saved: no cookies, no `localStorage`, no `chrome.storage`, no analytics, no tracking.
- No personal or sensitive information is sold or transferred to third parties.

## Permissions

The extension runs a content script on `https://chat.google.com/*` and `https://mail.google.com/*` (where Google Chat is embedded in Gmail). That is the only access it has, and it uses it only to render tables in the page you are viewing.
